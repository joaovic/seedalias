# i18n Implementation Plan for Seed Alias

**Created:** 2026-02-07  
**Status:** Ready for Implementation  
**Branch:** `i18n`

---

## Overview

This document outlines the plan for adding internationalization (i18n) support to Seed Alias, enabling users to switch between English (EN/US) and Brazilian Portuguese (PT-BR).

### Goals

- Add language switcher UI next to theme toggle in header
- Support English (default) and Brazilian Portuguese
- Persist language preference in localStorage
- No external dependencies - pure vanilla JS
- Translate all UI text including dynamic status messages

---

## User Interface Design

### Language Switcher

**Location:** Header, right side, next to theme toggle button

**Design:** Dropdown menu with emoji flags
- Button shows current language flag (🇺🇸 or 🇧🇷)
- Click to reveal dropdown with available options
- Click outside or select language to close

### 5. JavaScript Integration Points

**Existing files need minimal updates:**

**`js/interactions.js`** - Update dynamic status text:
```javascript
// Before
statusElement.textContent = 'Encrypted';

// After
if (window.i18n) {
  window.i18n.translateStatus(statusElement, 'encrypt.statusSuccess');
} else {
  statusElement.textContent = 'Encrypted';
}
```

**Alternative approach:** Store translation keys in data attributes, let i18n system handle updates

**`js/crypto.js` & `js/scramble.js`** - Same pattern for status updates

## Dynamic Content Strategy

### Challenge
Status messages change during user interaction ("Waiting" → "Encrypted"). These need to translate dynamically.

### Solution 1: Global Helper Function (Recommended)
```javascript
// In i18n.js - expose to window
window.setStatusText = function(element, statusKey) {
  const currentLang = getCurrentLanguage();
  const translation = getNestedTranslation(currentLang, statusKey);
  element.textContent = translation;
  element.setAttribute('data-i18n-status', statusKey);
};

// Usage in other files
window.setStatusText(statusBadge, 'encrypt.statusSuccess');
```

### Solution 2: Data Attributes
```html
<span data-i18n-status-key="encrypt.statusWaiting">Waiting</span>
```
```javascript
// When updating status
element.textContent = i18n.getText(element.dataset.i18nStatusKey);
```

## Notes

### Design Decisions

1. **No Dependencies:** Using vanilla JS to match existing codebase pattern
2. **Emoji Flags:** Simple, no external icon dependencies
3. **IIFE Pattern:** Following `theme.js` structure for consistency
4. **Dot Notation Keys:** `section.subsection.key` for organization
5. **Data Attributes:** `data-i18n` for static text, `data-i18n-status` for dynamic

### Technical Considerations

1. **localStorage Key:** `seedalias-language` (consistent with `seedalias-theme`)
2. **Language Codes:** ISO 639-1 + country code (`en-US`, `pt-BR`)
3. **Default:** `en-US` (broadest compatibility)
4. **Fallback:** If translation missing, show English
5. **RTL:** Not needed for EN/PT, but structure supports future addition

### Browser Compatibility

- Modern browsers (ES6+ required for `const`, arrow functions)
- localStorage required
- All target browsers supported by existing codebase
